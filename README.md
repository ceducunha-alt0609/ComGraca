# 🧼 Com Graça · Sabão Artesanal

> App de gestão para produção e venda de sabão artesanal em pedra.  
> Feito com amor para a Dona Graça. 💜

---

## ✨ Funcionalidades

- **📊 Dashboard** — estoque, receita do mês, devedores, gráfico de faturamento
- **🧼 Receitas** — ingredientes, custos, embalagens, kits e preço sugerido automático
- **💰 Vendas** — registro avulso ou por kit, WhatsApp direto para cobrar
- **📦 Estoque** — produção, histórico, alerta de estoque baixo
- **📈 Relatório mensal** — lucro estimado, meta, top clientes, exportar CSV e imprimir
- **⚙️ Configurações** — temas, metas, backup e restauração de dados
- **📲 PWA** — instala na tela inicial do celular ou PC, funciona offline

---

## 🚀 Como usar

### Opção 1 — GitHub Pages (recomendado)

1. Faça um fork deste repositório
2. Vá em **Settings → Pages**
3. Em *Branch*, selecione `main` e pasta `/ (root)`
4. Clique em **Save**
5. Acesse `https://SEU-USUARIO.github.io/com-graca`

### Opção 2 — Abrir direto no navegador

Baixe o arquivo `index.html` e abra no Chrome ou Safari.  
Não precisa de servidor — funciona 100% local.

---

## 💾 Dados

Os dados ficam salvos no `localStorage` do navegador do dispositivo.  
Use **Configurações → Backup** para exportar um `.json` e guardar no Google Drive ou WhatsApp.

---

## 🛠 Tecnologias

- React 18 (UMD, sem build)
- CSS custom properties (temas dinâmicos)
- LocalStorage para persistência
- Service Worker para modo offline
- PWA manifest para instalação nativa
